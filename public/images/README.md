# Fotografía editorial

Coloca aquí la fotografía de portada como `hero.jpg` (recomendado: 1600×2000 px,
vertical 4:5, menos de 400 KB, con licencia o derechos de uso para BJXMODA).

Si el archivo no existe, la portada muestra una composición tipográfica con los
cuatro arquetipos en su lugar. Para cambiar la ruta o el texto alternativo,
edita `src/data/media.js`.
